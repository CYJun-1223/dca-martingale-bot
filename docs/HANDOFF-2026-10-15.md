## 6. Run / test cheat sheet

```
npm install && npm run build      # dashboard -> dist/

npm run web                       # dashboard on http://127.0.0.1:8787
npm test                          # units + sim + parity + db (needs soxxbot_test DB)
node apps/server/bot.js check|trace|status|setup|alert [--bot=<id>]
```

Live orders need `LIVE_TRADING=1`; `runtime/STOP_ALL` (the Pause button) cancels resting orders. Hard invariants for any refactor: see `docs/CURRENT-STATE.md` §4.
